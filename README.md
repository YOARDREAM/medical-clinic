# Медицинская клиника

Учебное веб-приложение на Python, Flask и PostgreSQL. Содержит 11 таблиц, формы добавления, редактирования и удаления, историю осмотров и расчёт суммы счёта. Приложение рассчитано на локальный запуск с вымышленными данными. Роли сотрудников и личный кабинет пациента описаны в модели предметной области. Формы работают в едином учебном интерфейсе оператора.

## 1. Как подключить базу

Нужны Python 3.11+ и PostgreSQL 15+ с утилитами `psql` и `createdb`. Запустите PostgreSQL. Параметры примера:

| Параметр | Значение |
|---|---|
| Хост | `127.0.0.1` |
| Порт | `5432` |
| База | `clinic` |
| Пользователь | `clinic_user` |
| Строка подключения | `postgresql://clinic_user:YOUR_PASSWORD@127.0.0.1:5432/clinic` |

Откройте `psql -d postgres` от локального администратора PostgreSQL. Для установок с пользователем `postgres` используйте `psql -U postgres -d postgres`. В консоли выполните:

```sql
CREATE ROLE clinic_user WITH LOGIN;
\password clinic_user
CREATE DATABASE clinic OWNER clinic_user ENCODING 'UTF8';
\q
```

Замените `YOUR_PASSWORD` на заданный пароль. Спецсимволы в пароле для строки подключения кодируются по правилам URL. Команды ниже подходят для macOS/Linux. Выполняйте их из корня проекта в одном терминале.

```sh
export DATABASE_URL='postgresql://clinic_user:YOUR_PASSWORD@127.0.0.1:5432/clinic'
```

## 2. Как создать таблицы

```sh
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f sql/schema.sql
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f sql/seed.sql
```

Первый файл создаёт домены, таблицы, ограничения, триггеры и представление итогов счетов. Второй добавляет вымышленные строки и выполняется один раз после создания схемы. В PostgreSQL должен быть доступен модуль `btree_gist`; в Linux он поставляется с пакетом расширений PostgreSQL. Схема и данные рассчитаны на новую базу.

## 3. Как запустить приложение

### Быстрый запуск с Docker Desktop

Откройте Docker Desktop. В терминале из корня проекта выполните:

```sh
docker compose up --build --wait
```

Команда сама запускает PostgreSQL, создаёт таблицы, загружает демонстрационные данные и запускает Flask. Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). База в контейнере доступна приложению по адресу `db:5432`. Учебный пароль указан в `compose.yaml`, порт базы наружу не опубликован.

Для проверки на только что созданной демонстрационной базе выполните `python3 scripts/verify.py`. На GitHub тот же сценарий запускается в Actions при отправке кода. Чтобы остановить сервисы и сохранить данные, выполните `docker compose down`.

### Ручной запуск с установленным PostgreSQL

Выполните шаги 1 и 2, затем установите зависимости приложения:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Если порт занят, выполните `PORT=8001 python app.py` и откройте порт 8001.

Для демонстрации откройте «Записи на приём», попробуйте добавить две записи одного врача на пересекающееся время и проверьте, что вторая отклоняется. Для завершения существующей записи последовательно выставьте статусы «Подтверждена» и «Завершена». Затем добавьте результат осмотра или счёт по завершённой записи. Цены и проценты в выставленных счетах сохраняются по состоянию на выставление.
